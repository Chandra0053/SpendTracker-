# SpendTracker

A modern personal expense tracking application built with **SwiftUI**, **Core Data**, and **Combine** following the **MVVM architecture**. This project demonstrates my hands-on experience with contemporary iOS development practices and serves as part of my journey back into professional iOS development.

## Overview

SpendTracker helps users manage daily expenses, monitor spending habits, and maintain financial awareness through a clean and intuitive user interface.

The project focuses on building scalable, maintainable, and production-ready iOS applications using Apple's latest development frameworks and best practices.

## Key Features

* Add, edit, and delete expense records
* Categorize expenses for better tracking
* Real-time data updates using Combine
* Persistent local storage with Core Data
* SwiftUI-based responsive user interface
* Expense history and transaction management
* MVVM architecture for clean code separation
* Dark Mode support
* Error handling and data validation
